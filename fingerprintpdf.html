1. Executive Summary

Traditional voting mechanisms are susceptible to manual identification errors, voter impersonation, and fraudulent double-voting. This project presents a standalone, secure biometric electronic voting prototype that enforces the fundamental democratic mandate of "One Person – One Vote".

By integrating high-accuracy optical minutiae scanning with hardware-level state machine lockouts, the system eliminates duplicate votes in real-time, displays immediate voting telemetry, and computes transparent tallies without network vulnerability.

3. System Workflow & Verification Logic

  1. Admin Enrollment Mode: Master biometric verification initiates voter onboarding. Minutiae templates are indexed into non-volatile internal EEPROM with a default state flag set to HasVoted = FALSE.
  2. Biometric Authentication: A voter places their finger on the optical sensor. The onboard DSP executes template matching against registered IDs. Unrecognized prints are denied with an onscreen alert.
  3. Vote Polling & Duplicate Prevention: If HasVoted == FALSE, tactile polling keys activate, registering the candidate preference. The flag immediately toggles to HasVoted = TRUE. Any subsequent attempt triggers an audio buzzer alarm and displays "Already Voted" on the LCD.

5. Security & Efficiency Gains

Multi-iteration benchmark testing demonstrated marked improvements across fraud mitigation and voter throughput speed:

  • Turnaround Efficiency Index: Scaled progressively across 4 test attempts from 1.20 up to a peak index of 3.40 (compared to 2.40 on legacy setups).
  • Security Index: 0% duplicate vote allowance across all concurrent voter attempts.

6. Engineering Highlights

  • Low-Latency UART Link: Fast serial protocol between sensor DSP and ATmega328P ensuring sub-second response times.
  • Air-Gapped Security: Embedded standalone design operates without internet connectivity, preventing external cyber attacks.
  • Power Efficiency: Optimized 5V/9V low-power supply suitable for portable deployment.
